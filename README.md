LiterAlura
LiterAlura é uma aplicação Java para gerenciamento e busca de informações literárias. A aplicação oferece diversas funcionalidades que permitem a interação com um acervo de livros e autores, tornando-a uma ferramenta prática e intuitiva para amantes de literatura.

Funcionalidades
Ao executar o programa, o usuário pode selecionar as opções abaixo:

Buscar livro pelo título: Encontre um livro específico pelo título cadastrado no sistema.
Buscar livros por autor: Descubra todos os livros de um autor registrado no sistema.
Listar livros registrados: Veja a lista completa de todos os livros cadastrados.
Listar autores cadastrados: Consulte os nomes de todos os autores disponíveis no sistema.
Listar autores vivos em determinado ano: Insira um ano e obtenha uma lista de autores que estavam vivos naquele período.
Listar livros em determinado idioma: Filtre os livros cadastrados por idioma.
Sair: Encerre a execução do programa.
